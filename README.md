One emoji that stands for the agent morningshine: 🐈‍⬛ — a black cat. Sharp-eyed, quiet, nocturnal, always watching the chain while everyone else sleeps. It reads instantly at small size, it is specific to this agent (a black cat, not the obvious robot or smiley half the field will send), and its tone fits: playful, a little grumpy, awake at 3am. The program writes that single glyph — nothing else — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
